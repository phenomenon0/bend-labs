# bend-labs — the workshop: proofs, reports, showcases

Everything here is measured; every number cites a receipt under `docs/omen/lanes/`.

- `docs/omen/` — governance (BOUNDARY.md, FLOW.md, PROOF-GATE.md), lane reports
  (one per lane: what shipped, the numbers, the deviations), plans.
- `demos/` — the showcase programs built for the video kit / tweets:
  `text/` (md2html, topwords, bendgrep, slices), `text_stream/`,
  `strings_tour/` (the hostile-log tour), `parallel/` (thread knob, GPU lane),
  `regex/`.
- Apple-lab scripts live in `docs/omen/apple/` (parse_scale, decode_bench,
  measure_watts, bench_pins — the M3 Ultra rigs).

History filtered from the bend fork (all commits preserved). The video kit
itself lives beside this repo at `~/Documents/Project/bend-strings/video-kit`.
